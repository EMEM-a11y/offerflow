## 日常维护与回滚

- GitHub Actions 每天 01:23 UTC 计划运行，可能延迟，不是实时任务。公开仓库长时间无活动可能暂停定时工作流，应关注 Actions 状态。
- 自动更新仅覆盖配置的数据源；公司投递规则仍需人工核对。用页面来源时间判断新鲜度。
- 源站失败或数据骤减会阻止发布；查看日志、确认来源后再重跑，不把旧快照标记成刚抓到的新数据。
- 发布代码可回退到已验证的 Git 版本并重跑；代码回滚不会恢复 Supabase 数据，数据恢复依赖独立备份。
- 无需让本机或 Codex 持续开启。免费服务仍有额度和可用性限制，不承诺永久免费或持续在线。
