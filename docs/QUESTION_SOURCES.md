# 题库来源与使用原则

## 当前启用题源

- `GitHub 北森社区题库`：主训练池来自 `minnielv/beisen-quiz`，原始共 719 题（言语 315、资料 252、图形 152）；经过质量筛选及去重后接入，实际可练数量以页面载入结果为准。页面运行时从固定版本载入，保留原仓库链接，并明确标注“社区整理，非北森官方”。
- `政府官网公开例题`：湖北省 2026 年公务员公共科目笔试考试大纲中的公开例题。每道题保留官方原文链接。
- `用户提供 PDF`：用于录入“京东测评真题 · 第 2 套”的首批题目，以及从第 1、3、4、5 套和两份汇总资料中筛选出的 28 道增补题。扫描页先经过本地文字识别，再逐页核对题干、选项、答案和解析。
- `添加我的题库`：登录用户导入的 JSON 题库保存到自己的账号，不会自动加入公共共享题库。项目已经内置的共享试题对访客开放。

原创模拟、规则生成图推，以及与北森备考无关的 GitHub 公务员聚合题已从产品题库下线，不再参与专项抽题或套卷。

社区题库在载入时会按规范化题干与本地 PDF 题库去重。题库内容不写入用户的云端数据，原题图片也不复制进项目仓库。本地与公开版使用相同的启用题源和质量筛选，不单独删减公开版。

## 北森官方资料

- 北森官网《校招中如何运用测评工具》公开了九类能力测验的题型说明和少量样题。平台仅提供官方原文入口，不复制或拼装北森未公开题库。
- 北森 CATA 官方说明表明其采用自适应抽题并持续扩充题库，网上流传的固定“北森真题套卷”不能据此认定为官方题库。

- `Liqing-Lin/BeiSen_Practice`：用于交叉核对题量和题型，其 README 标注 445 道北森专项题。因与主训练池高度重叠，不重复接入。
- `Phillipwu2233/beisen-tiku`：用于交叉核对结构与答案，不重复接入。

- `fei98/civil-service-exam-prep`：参考专项训练、套卷、错题本和统一题库字段，并使用其公开学习数据。仓库代码采用 MIT；其说明要求题面和解析仅作个人学习，相关权利归原作者所有。
- `mpbfx/gongkao`：参考训练流程、离线草稿和按知识点复习的产品机制。该项目采用 AGPL-3.0，不直接复制其实现代码。
- `Why-com-ui/gongkao-practice.skill`：参考 Markdown、CSV、Excel 和 JSONL 的题库标准化思路。
- `aranvhout/OMSS_generator`：参考其公开的矩阵推理规则分类，包括递增、属性变化和组合关系；OfferFlow 使用独立实现生成 SVG 题目。

## 约束

- 不抓取或传播测评机构未公开的商业题库。
- 第三方题目在接入前需要确认来源、许可证和使用范围。
- 用户上传题库应确保自己拥有使用权限。
- 页面中的来源标记不得删除或改写为 OfferFlow 原创。
