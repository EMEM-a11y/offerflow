## 已确认的提取缺陷

上游 `scripts/extract_questions.py` 中，选项数不足时默认四项，只有答案为 E 才补到五项；`_content_bands` 强制合并/拆分到指定数量。原图有五项而答案不是 E 时就可能合并两个选项。资料图则按页面答案数分配图片，缺少逐题对应证明。

`graph-110`：第 327 页 `p327_4_4882.png` 为题干；第 328 页 `p328_1_4892.png` 从上到下明确有五项。旧 A 图把前两项合在一起。现保留完整原图，提供 A–E 五个位置选项，答案仍为 A，使用新 ID `community-beisen-graph-110-reviewed-v2`，不将旧版作答套到新版。

`graph-60`：至少一个选项没有图片，但占位文字使旧完整性校验放行。现图片选项单独校验。

`jd-supp-09/17/21/27`：缩写文本遗漏解析或选项依赖的情绪定义、旧认知、肝脏或环境信息。保留原数据和历史，待 PDF 比对，不凭解析反向补写题干。

## 防止复发

1. 导入检查标签顺序、答案范围、空答案、选项重复、图片缺失/重复、题干选项图片串用、素材路径；单条坏数据隔离，不拖垮整库。
2. 社区图片题默认待核验，不因文件存在就放行。恢复需记录原始版本、页码、题干图、实际选项数和顺序、正确答案及核验依据；不依赖答案字母猜选项数，不强制等分图片。
3. 修订影响选项映射时用新版本 ID；旧历史不删除、不重新判分，旧题不进入新训练。进行中的不可用题跳过，不计入本次分母。
4. 图片加载失败时临时跳过，不要求用户盲选；完整原图可打开查看。
5. 发布流程运行全量结构审计和回归测试。`pnpm check:questions` 可重新生成逐题审计记录；也可传入已下载的固定版本 JSON 离线复核。

后续恢复必须真实完成原图核对，不能仅移除暂停条件。尚未完成的工作：403 题的逐题题源核验，以及全部文本题的独立语义复核。
